What I do on an engagement

I work best with engineering-led companies that need a security architect for a defined outcome: a platform to secure before launch, an environment to harden, an architecture review before the auditors arrive.

Platform security architecture

Zero-trust service mesh with Istio mTLS, WAF and ingress design, least-privilege IAM, KMS encryption, secrets in Vault, hardened network segmentation, and immutable backups that beat ransomware.

Guardrails live in the pipeline (Checkov, tflint, Checkmarx, code signing) so misconfigurations never reach production.

Audit-ready by design

I map the architecture to SOC 2, PCI-DSS and ISO 27001 controls up front and build the evidence pipeline into the platform.

Compliance becomes a property of the system rather than a quarterly scramble.

Security operations foundation

SIEM design and deployment on Splunk, SumoLogic and LogRhythm, plus CrowdStrike, Nessus, GuardDuty and PKI.

I have run incident response and reported post-mortems to executives at four companies, so the architecture reflects what actually fails at 2 a.m.

Open to fractional and part-time security engagements alongside my current role, remote from Virginia.
